# Pilog Tray Icon Variants

These are small-system-icon explorations generated from the main Pilog app icon direction.

- `pilog-tray-variant-01-folded-page.png` — simplest direct read: a folded warm page with the moss pi stroke.
- `pilog-tray-variant-02-pi-bookmark.png` — strongest small silhouette: moss pi mark over a reduced paper tab.
- `pilog-tray-variant-03-note-stack.png` — closest to the journal/workflow metaphor: compact stacked notes plus the moss mark.
- `pilog-tray-note-stack.png` — manually cleaned and trimmed note-stack candidate now being tried in the app tray. The optimized runtime copy is `resources/tray-icon.png`.

Each variant includes:

- `*.png` — 512px transparent candidate asset.
- `*-32.png` — 32px tray-size preview.
- `*-preview-dark.png` / `*-preview-light.png` — quick contrast previews against dark and warm-light tray backgrounds.

Tray-icon intent: preserve the warm paper + Reading-Room moss relationship from the app icon, remove page lines and decorative shadows, and keep the silhouette readable at 16-32px.
